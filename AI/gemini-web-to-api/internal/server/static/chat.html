Hướng Dẫn Lấy Cookie Google Gemini

Dự án gemini-web-to-api sử dụng phiên làm việc (Session Cookies) của tài khoản Google của bạn để giao tiếp trực tiếp với Gemini Web mà không cần API Key có phí.

1
Truy cập Gemini: Mở trình duyệt và đăng nhập vào gemini.google.com.
2
Mở Developer Tools: Bấm phím F12 (hoặc chuột phải chọn Inspect / Kiểm tra) -> Chuyển sang thẻ Network (Mạng).
3
Tìm Request: Tải lại trang (F5) hoặc gửi 1 tin nhắn bất kỳ. Gõ vào ô Filter: batchexecute.
4
Sao chép Cookie: Bấm vào request batchexecute?rpcids=otAQ7b -> Trong tab Headers -> Cuộn xuống mục Request Headers -> Copy toàn bộ chuỗi giá trị của dòng Cookie: (bắt đầu chứa __Secure-1PSID=...).
5
Cấu hình file .env: Mở file .env trong thư mục dự án và dán vào biến GEMINI_COOKIES=..., sau đó chạy lại run.bat.
Mẹo: Nếu tài khoản Google của bạn là tài khoản phụ (ví dụ URL có dạng /u/1/ hoặc /u/2/), hãy điền thêm số tương ứng vào GEMINI_AUTH_USER=1 hoặc GEMINI_AUTH_USER=2 trong file .env.
