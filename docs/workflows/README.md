## 🎯 Tổng quan (Overview)

SmartFlow v2 có 5 luồng nghiệp vụ chính:

1. **Delivery Flow** - Luồng bàn giao linh kiện
2. **Production Flow** - Luồng sản xuất
3. **QC Flow** - Luồng kiểm tra chất lượng
4. **Notification Flow** - Luồng thông báo
5. **Return Flow** - Luồng trả hàng

---

## 📑 Workflow Categories

### 1. Delivery Flow

- Tạo phiếu giao
- Quét mã QR
- Xác nhận nhận hàng
- QC kiểm tra
- Hoàn thành phiếu

### 2. Production Flow

- Tạo kế hoạch sản xuất
- Tạo đơn hàng
- Theo dõi tiến độ
- Hoàn thành đơn hàng

### 3. QC Flow

- Kiểm tra đầu vào
- Kiểm tra công đoạn
- Kiểm tra hàng ngày
- Đánh giá kết quả

### 4. Notification Flow

- Tạo thông báo
- Gửi thông báo
- Đọc thông báo
- Đánh dấu đã xem

### 5. Return Flow

- Tạo phiếu trả
- Xác nhận trả
- Cập nhật kho
- Hoàn thành
